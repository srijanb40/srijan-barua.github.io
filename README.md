# srijanb40.github.io

Personal portfolio site, plain HTML/CSS hosted on GitHub Pages.

## Structure
`index.html`, `about.html`, `projects.html`, `certifications.html`, `blog/*.md` (rendered by Jekyll via `_layouts/post.html`), `css/style.css`, `assets/`.

## Publish
1. Copy these files into the repo `srijanb40.github.io` (root of `main`).
2. Settings → Pages → Deploy from a branch → `main` / root.
3. Visit https://srijanb40.github.io/ after the Actions run turns green.

## Before going live
- Replace `YOUR-PROFILE` in the LinkedIn links.
- Confirm each project link points to a real repo.
- Add badges to `assets/certifications/` and images to `assets/images/`.
- Keep employer names, internal hostnames and secrets out of every file.
